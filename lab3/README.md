# Лабораторная работа №3

Анализ и моделирование данных предметной области

**Цель работы:**
Изучить принципы анализа предметной области и моделирования данных, научиться выделять основные объекты информационной системы, определять их характеристики и взаимосвязи.

**Предметная область:**
Образовательная платформа (онлайн-обучение)

**Краткое описание:**
В ходе работы были выделены основные объекты предметной области (студенты, преподаватели, курсы, задания и результаты), определены их атрибуты и типы данных, выполнена классификация данных и построена концептуальная (инфологическая) модель данных.
