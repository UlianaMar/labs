# Лабораторная работа №4

**Тема:** Анализ учебного набора данных с помощью SQL.

**Предметная область:** Образовательная платформа (учебные группы, студенты, преподаватели, курсы, записи на курсы, оценки).

**Цель работы:** Научиться анализировать данные из нескольких связанных таблиц с помощью SQL, применять фильтрацию, сортировку, агрегирование, группировку и объединение таблиц; проверять целостность данных и формулировать аналитические выводы.

## Описание предметной области

Рассматривается образовательная платформа, которая хранит информацию о студентах, их распределении по группам, учебных курсах, преподавателях, записавшихся на курсы студентах и выставленных им итоговых оценках.

Учебная база данных SQLite содержит шесть связанных таблиц:

| Таблица | Назначение | Количество записей |
| :--- | :--- | :--- |
| `groups` | Учебные группы | 12 |
| `students` | Студенты | 240 |
| `teachers` | Преподаватели | 15 |
| `courses` | Курсы | 30 |
| `enrollments` | Записи студентов на курсы | 1000 |
| `results` | Итоговые оценки завершенных записей | 850 |
| **Итого** | | **2 147** |

Таблицы связаны между собой с помощью первичных и внешних ключей. Это позволяет анализировать успеваемость студентов, популярность курсов, нагрузку преподавателей и другие показатели.

Для выполнения SQL-запросов используется онлайн-среда SandboxSQL.

## Выполненная работа

В ходе лабораторной работы:

1. Загружена база данных SQLite, проверено наличие шести таблиц и количество записей в каждой из них.
2. Изучены структура таблиц, их поля, первичные и внешние ключи. Сформулированы аналитические вопросы.
3. Выполнена фильтрация и сортировка данных с помощью `WHERE`, `ORDER BY` и `LIMIT`.
4. Рассчитаны агрегированные показатели с использованием `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`. Выполнены группировка с `GROUP BY` и фильтрация групп с `HAVING`.
5. Исследованы связи между таблицами с помощью `INNER JOIN` и `LEFT JOIN`.
6. Выполнены проверки корректности данных и ссылочной целостности (поиск некорректных оценок и "сиротских" записей).
7. Проведено самостоятельное аналитическое исследование **(Вариант 2: какие учебные группы показывают лучшие средние результаты обучения, с учётом числа оценок)**, сформулированы выводы на основе результатов SQL-запросов.

## Результат

Подготовлен аналитический отчет, содержащий описание структуры базы данных, аналитические вопросы, SQL-запросы, таблицы результатов, скриншоты их выполнения в SandboxSQL и выводы по каждому шагу.

По результатам анализа исследована успеваемость студентов в разрезе учебных групп, рассчитаны средние баллы, оценено влияние объема данных (количества оценок) на итоговые показатели, а также проверена корректность хранящихся данных.
